# DESIGN SYSTEM

# Holiday Banyuwangi — Globeon Inspired Redesign

---

## 0. PROJECT OBJECTIVE

This project is a complete VISUAL AND UX REDESIGN of the existing Holiday Banyuwangi website.

The website must preserve the ORIGINAL HOLIDAY BANYUWANGI CONTENT while allowing the AI agent to completely redesign:

* layout
* section composition
* visual hierarchy
* spacing
* grid
* card structure
* navigation presentation
* hero composition
* image placement
* typography hierarchy
* interactions
* transitions
* animations
* responsive layout

The primary visual reference is:

Globeon Webflow Travel Template

https://templates.webflow.com/html/globeon-website-template

The existing Holiday Banyuwangi website is the SOURCE OF TRUTH FOR CONTENT.

https://holidaybanyuwangi.com/

---

# 1. FUNDAMENTAL RULE

The project has two completely separate layers:

# CONTENT LAYER

Holiday Banyuwangi

# DESIGN LAYER

Globeon-inspired redesign

The AI agent has full freedom to redesign the DESIGN LAYER.

The AI agent has NO freedom to modify the CONTENT LAYER.

---

# 2. CONTENT MUST REMAIN EXACTLY THE SAME

The following must remain exactly as they appear on the existing Holiday Banyuwangi website:

### Text

Preserve exactly:

* headings
* subheadings
* paragraphs
* package names
* destination names
* descriptions
* pricing
* duration
* CTA text
* navigation labels
* testimonial text
* contact information
* address
* phone numbers
* email addresses
* social media information
* footer text
* business information

Do NOT:

* rewrite
* paraphrase
* summarize
* translate
* shorten
* expand
* correct grammar
* improve copywriting
* generate alternative wording

Even if the existing copy appears poorly written, preserve it exactly.

---

# 3. IMAGES MUST REMAIN THE SAME

Use the original Holiday Banyuwangi images.

Do not replace them with:

* AI-generated images
* stock photography
* Globeon images
* random internet images
* placeholder images

The same image assets must remain.

However, the AI agent MAY completely change how the images are presented.

Allowed:

* image size
* crop
* aspect ratio
* position
* image order
* image placement
* full-screen image
* split-screen image
* overlapping image
* image carousel
* image slider
* image reveal
* image hover effect
* parallax
* image masking
* image transitions

The asset itself must remain unchanged.

---

# 4. LAYOUT IS NOT LOCKED

IMPORTANT:

* rearrange content

* create asymmetric layouts

# 8. COLOR PHILOSOPHY

Green should dominate the visual identity without making the entire website green.

Recommended balance:

60% neutral / warm white
25% deep green
10% soft green
5% supporting accent

Do NOT use:

* neon green
* lime green
* purple gradients
* blue/purple AI gradients
* rainbow gradients
* excessive color variation

Use natural tonal green combinations.

---

# 18. ANIMATION SYSTEM

Animation is an important part of the redesign.

Animations should feel like a premium Webflow travel website.

### Page Load

Use:

* subtle fade
* upward movement
* staggered typography
* image reveal

Duration:

600–1000ms

Use easing such as:

ease-out
cubic-bezier transitions

---

# 19. SCROLL ANIMATIONS

Use subtle scroll-based animation.

Examples:

* fade-in sections
* image reveal
* text reveal
* staggered cards
* image scale
* horizontal scrolling
* subtle parallax

Animations should be meaningful.

Do NOT animate every element.

---

# 20. IMAGE ANIMATION

Preferred:

* scale on hover
* image reveal
* clip-path reveal
* subtle zoom
* horizontal image movement
* parallax

Example:

Image starts slightly zoomed:

scale(1.05)

On scroll:

scale(1)

Keep animation subtle.

# 21. CARD ANIMATION

On hover:

Do not use:

---

# 25. RESPONSIVE DESIGN

Desktop and mobile may have different layouts.

Desktop can use:

* asymmetric grids
* horizontal layouts
* overlapping elements
* large typography
* cinematic images

Mobile should use:

* vertical storytelling
* swipeable sections
* full-width images
* simplified animation
* readable typography

The content remains identical.

---

# 26. MOBILE ANIMATION

Reduce animation complexity on mobile.

Use:

* fade
* slide
* simple image reveal

Avoid:

* heavy parallax
* large transform animations
* complex horizontal effects that hurt usability

---

# 27. PERFORMANCE

Animations must not significantly reduce performance.

Prefer:

* transform
* opacity
* CSS animation
* GPU-friendly properties

Avoid unnecessary JavaScript animation.

Respect:

prefers-reduced-motion

If users disable animation:

provide a reduced-motion experience.

---

The website should feel intentionally art-directed.
